# Teksty zakładki Aplikacja (sekcja Funkcje)

Polecany: wariant B.

## Wariant A
- Zakładka: Aplikacja
- Nagłówek h3: Wpisz cel, resztę zrobi agent.
- Zachęta: Wpisz w oknie własny cel i zobacz, jak agent bierze się do pracy.
- Podpis: To pokaz na przykładowych danych. Nic nie wychodzi z twojego komputera.

## Wariant B (polecany)
- Zakładka: Aplikacja
- Nagłówek h3: Sprawdź LumoBota sam.
- Zachęta: Wpisz cel w oknie poniżej i zobacz, jak agent pracuje do skutku.
- Podpis: Okno działa na pokazowych danych. Nic nie wychodzi z twojego komputera.

## Wariant C
- Zakładka: Okno
- Nagłówek h3: Tak wygląda praca z agentem.
- Zachęta: Napisz cel w oknie. Agent ruszy, a sprawdzenie powie, czy się udało.
- Podpis: To pokaz, nie prawdziwe zadanie. Dane są przykładowe i zostają na tym komputerze.
