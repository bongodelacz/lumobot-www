GitHub i Figma

Agent zna twoje repozytoria i projekty. Porządkuje zgłoszenia, opisuje zmiany i buduje strony, które wyglądają jak makieta w Figmie.

Co potrafi

GitHub

Zgłoszenia, pull requesty i repozytoria. Agent czyta otwarte zgłoszenia, opisuje zmiany i przygotowuje pull requesty. Łączysz go osobistym tokenem GitHub, który wpisujesz sam w ustawieniach.

Figma

Odczyt projektów: układ, kolory i komponenty. Agent bierze wartości prosto z makiety, więc strona trzyma odstępy i kolory projektanta. Figmę łączysz, logując się w przeglądarce.

Przykładowe zadania

Piszesz zwykłym zdaniem w czacie LumoBota, na przykład:

  • „Przejrzyj otwarte zgłoszenia w repozytorium i wypisz trzy najpilniejsze.”
  • „Opisz zmiany z tej gałęzi i przygotuj pull request, ale go nie publikuj.”
  • „Odczytaj z Figmy kolory i odstępy i zbuduj stronę zgodną z makietą.”
  • „Porównaj stronę z projektem w Figmie i wypisz różnice.”

Działa razem: Praca do skutku

Przy kodzie zadanie kończy się dopiero, gdy przejdzie sprawdzenie, na przykład testy. Każda zmiana idzie na osobnej gałęzi git, więc główna gałąź zostaje nietknięta.

Bezpieczeństwo

Hasła zostają u ciebie

Hasła, które podajesz w LumoBocie, są zaszyfrowane na twoim komputerze. Nie trafiają do chmury ani do modelu AI. Do kont logujesz się sam w przeglądarce agenta, a agent pracuje na gotowej sesji i nie zna hasła.

Projekty i dane na twoim dysku

Wszystkie projekty, pliki i ustawienia zostają w folderach na twoim komputerze. LumoBot nie ma własnej chmury i nie przesyła nam twoich danych.

Ty decydujesz, co wychodzi

Do dostawcy AI, którego sam wybierzesz, trafia tylko treść zadania. Z modelem lokalnym, na przykład Ollama albo LM Studio, nic nie opuszcza komputera. Zanim agent coś wyśle albo opublikuje, pokazuje gotową treść i czeka na twoje „tak”.

Jak zacząć

  1. Włącz w LumoBocie narzędzie GitHub i wpisz sam swój osobisty token GitHub.
  2. Włącz narzędzie Figma i zaloguj się do Figmy w przeglądarce agenta.
  3. Napisz zadanie w czacie, na przykład: „Wypisz pilne zgłoszenia w moim repozytorium”.

Pytania

Logujesz się sam, agent nie zna hasła i pyta o zgodę, zanim cokolwiek wyśle.

Wszystkie wtyczki ›
Czy agent zna mój token GitHub?

Token wpisujesz sam w ustawieniach LumoBota. Agent z niego korzysta, ale nie prosi o niego w czacie i nie pokazuje go w rozmowie.

Czy agent opublikuje pull request bez mojej zgody?

Nie. Przed publikacją pokazuje treść i czeka na twoje zatwierdzenie. LumoBot niczego nie publikuje sam.

Czy agent zmieni mój projekt w Figmie?

Nie. Połączenie z Figmą służy do odczytu: układu, kolorów i komponentów. Twoja makieta zostaje bez zmian.

Co, jeśli agent zepsuje kod?

Każde zadanie idzie na osobnej gałęzi git, a po każdej rundzie powstaje punkt powrotu. Zawsze możesz do niego wrócić.

Ile to kosztuje?

LumoBot kosztuje 0 zł, a narzędzia są w cenie. Płacisz tylko za plan AI, który już masz.
