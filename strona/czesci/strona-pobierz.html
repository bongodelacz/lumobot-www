Trzy kroki.
Potem już tylko cele.

  1. 1

    Zainstaluj

    Uruchom LumoBot-Setup i przejdź przez instalator. Skrót pojawi się w menu Start.

  2. 2

    Podłącz AI

    Zaloguj się do Claude albo ChatGPT, dodaj klucz Gemini, Mistrala lub OpenRoutera, albo wskaż Ollamę i LM Studio. Lokalne modele działają bez opłat.

  3. 3

    Napisz cel

    Wskaż folder projektu i napisz, co ma być zrobione. Agent pracuje, aż sprawdzenie przejdzie.

Wymagania

System
Windows 10 albo 11, 64 bity
AI
Konto Claude lub ChatGPT, klucz API (Gemini, Mistral, OpenRouter) albo model lokalny (Ollama, LM Studio)
Miejsce
Folder projektu, w którym agent ma pracować. Najlepiej z git, wtedy działają punkty powrotu
Aktualizacje
Automatyczne. Program sprawdza nowe wydania i aktualizuje się po jednym kliknięciu
