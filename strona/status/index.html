Status

LumoBot działa na twoim komputerze, więc nie ma serwerów, które mogłyby paść. Tu sprawdzisz wersję i usługi, z których korzysta.

Aplikacja

Działa na twoim komputerze. Najnowsza wersja: 0.27.42.

Twoje dane

Projekty i hasła zostają na dysku. LumoBot nie ma własnej chmury.

Aktualizacje

Pobierane z GitHub Releases. Gdy GitHub ma przerwę, aplikacja działa dalej.

Dostawcy AI

Działanie zależy od wybranego dostawcy. Model lokalny nie potrzebuje internetu.

Co może przestać działać

LumoBot nie ma serwerów, które mogłyby paść. Gdy coś nie działa, przyczyna jest zwykle po stronie usługi, z której korzysta zadanie:

  • dostawca AI, na przykład Claude albo ChatGPT, ma przerwę albo wyczerpałeś limit planu,
  • strona, na której pracuje przeglądarka agenta, nie odpowiada,
  • GitHub nie wydaje aktualizacji, więc nowa wersja przyjdzie później.
